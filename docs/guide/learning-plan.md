## 二、阶段1：Node.js 夯实（约 4 个月）
### 目标
不是只写脚本；懂事件循环、Stream、Buffer、异步模式、错误处理、安全基础（XSS/CSRF/输入校验）、REST 接口、数据库交互、基础部署。

### 学习步骤（方法铁律）
1. 先过官方文档，不一开始就刷一堆旧 B 站教程
2. 「概念 → 小 Demo → 踩坑记录 → 重构」流程，每个重要知识点手写至少一个小 Demo
3. 区分「会用库 ≠ 懂底层」，不要永远停留在 npm install 调接口
4. 踩坑笔记用 Markdown 存到本仓库

### 每月任务
| 月份 | 主题 | 任务 | 案例 / 产出 |
|---|---|---|---|
| 第1月 | 基础 + 异步 | 语法巩固、模块、事件循环、fs、path、http | 文件处理小工具、简单静态服务器 |
| 第2月 | 异步进阶 + Stream/Buffer | 流、Buffer、错误处理、EventEmitter | 大文件读写、日志流处理工具 |
| 第3月 | Express + 中间件 | 路由、中间件、参数校验、错误处理 | `express-jwt-api` 登录接口（本仓库） |
| 第4月 | 数据库 + 安全 + 部署 | MySQL/低依赖库、JWT、XSS/CSRF、部署 | 完成 `01-express-jwt-api` 完整 Demo |

### 学习资料
- 官方：[Node.js 中文文档](https://nodejs.org/zh-cn/docs)
- 书籍：《深入浅出Node.js》（朴灵，挑章节读）、《Node.js设计模式》
- 视频（辅助）：B站「尚硅谷Node.js」「李立超nodejs」
- 练习：GitHub 搜 nodejs-practice；LeetCode 简单–中等 JS 题

### 验收标准
独立完成带 JWT 登录、文件上传、基础权限、可部署到云服务器的 REST API。

## 三、阶段2：NestJS 工程化（约 5 个月）
### 目标
从「写服务脚本」走向企业级后端架构；与前端 TS 无缝衔接。

### 学习顺序（严格按此）
1. 先啃官方文档：[docs.nestjs.cn](https://docs.nestjs.cn)
2. 基础模块 → 依赖注入 → 中间件/守卫/拦截器/管道/异常过滤器 → ORM(TypeORM/Prisma，优先 Prisma) → 微服务入门、配置、日志、测试(Jest)、Docker 部署
3. **一定要写测试**；学 DDD 基础思想（不用极端复杂）

### 每月任务
| 月份 | 主题 | 案例 |
|---|---|---|
| 第1月 | 模块 + DI + 基础路由 | 简单 CRUD 模块 |
| 第2月 | Guards/Pipes/Interceptors/ExceptionFilter | 登录鉴权、参数校验、响应格式化 |
| 第3月 | TypeORM + 数据库 + RBAC | `nest-rbac-backend` 权限系统（本仓库） |
| 第4月 | Swagger + 测试 + 日志 + 配置 | 为 RBAC 项目补全接口文档与单测 |
| 第5月 | Docker 部署 + 项目重构 | 将 express 项目迁移重构为 Nest 版本 |

### 学习资料
- 官方文档（第一优先级）
- 书籍：《NestJS实战：使用TypeScript开发企业级Node应用》
- B站辅助：「全栈小铭 NestJS系列」「码农小周 NestJS」
- 开源参考：GitHub 搜 nestjs realworld

### 验收标准
完成一个可运行、有 Swagger 文档、有基础单测、可 Docker 部署的 Nest 后端，并与 Vue3/uniApp 前端打通。

## 四、阶段3：Python + FastAPI + AI 工程（约 7–9 个月）
### 定位
不是当算法科学家，是「全栈工程师能用 Python 解决工程问题」：后端服务 + 数据处理 + AI 工程封装。

### 学习顺序
1. Python 基础语法、数据结构、异常、文件、面向对象（1.5 个月）
2. 现代工程：venv、poetry、类型提示 typing、单元测试、常用标准库（1 个月）
3. Web 后端：FastAPI（优先）、Flask 了解、Django 了解生态（2 个月）
4. 数据处理：Numpy、Pandas、Matplotlib 基础；数据清洗、简单可视化（2–3 个月）
5. AI 工程：LangChain、OpenAI API、简单 RAG、本地大模型部署入门（1–1.5 个月，只做调用与工程封装）

### 案例 / 产出（本仓库）
- `python/01-py-scripts`：数据清洗脚本、批量处理脚本、小工具
- `python/02-fastapi-rag-demo`：文档上传、切片、向量化、RAG 检索问答
- 一个「文档问答」小前端打通演示

### 学习资料
- 官方：python.org、fastapi.tiangolo.com
- 书籍：《Python编程：从入门到实践》、《流畅的Python》（选读）
- B站辅助：「黑马程序员Python入门」；《FastAPI官方教程中文版》
- 练习：LeetCode Python；把 Node 小工具用 Python 重写一版对比

### 验收标准
一个 FastAPI 后端 + 简单数据导入导出 + 对接公开 AI 接口的「文档问答」Demo，与前端打通。

## 六、外语学习（并行，贯穿全程）
> 外语是长期习惯，不是「可以学完通关」的项目；每天固定小块，不抢技术深度时间。

### 每日时间
| 内容 | 工作日 | 周末 |
|---|---|---|
| 英语 | 30–45 分钟 | 可增加精读 30–60 分钟 |
| 日语 | 15–20 分钟（可跳过，别硬逼） | 视精力而定 |

### 英语路线
1. 基础：语法 + 词汇；优先「技术词汇 + 通用词汇」；用 Anki 自建词卡
2. **核心方法：技术精读**——每周 2 篇英文技术文章 / 开源 README / MDN / Nest 文档，逐段看懂并摘抄
3. 进阶：YouTube 技术博主（The Net Ninja、Fireship），开英文字幕
- 免费资源：B站「英语的平行世界」语法系列；Coursera 免费课

### 日语路线（兴趣，3–5 年缓慢推进，不赶）
1. 五十音 → 新标准日本语初级（B站「叶子老师新标日」；APP：MOJi辞書）
2. 中级后看日文技术博客 zenn.dev，把日语与技术阅读结合
- 目标：N3–N2，能看懂简单日文技术博客即可

> ⚠️ 外语不挤占每天 1.5h 以上深度技术时间；它是甜点，不是主菜。
