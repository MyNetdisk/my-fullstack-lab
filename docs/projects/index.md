# 项目总览

my-fullstack-lab 存放学习全栈过程的Demo，非生产项目，用于练习与知识点沉淀。

## 项目列表
- [express-jwt-api](./express-jwt-api) Express JWT登录接口
- [nest-rbac](./nest-rbac) NestJS RBAC权限管理
- [fastapi-rag](./fastapi-rag) FastAPI简单RAG服务
- [py-scripts](./py-scripts) Python小工具脚本
- [vue-frontend](./vue-frontend) Vue前端，对接后端接口

新增项目请看：[新增项目规范](../guide/add-new-project)
